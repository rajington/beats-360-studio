# Beats 360 Studio — 256 combos

Unofficial fan-made visualizer for all 256 Beats 360 color combinations.
Pick a frame color, ear cushion color/material, and headband cushion
color/material, and preview the combo. Includes a clickable gallery of
all 256 combinations and shareable `#f-e-h` links.

Fan concept. Not affiliated with Beats or Apple. Colors are approximations.

## Run locally

Just open `index.html` in a browser. No build step, no dependencies.

## Deploy to GitHub Pages

1. Create a new repo and push this folder's contents to the `main` branch.
2. In the repo: **Settings → Pages → Source: Deploy from a branch**,
   branch `main`, folder `/ (root)`.
3. Your site will be live at `https://<you>.github.io/<repo>/` in ~a minute.

## Customizing

- Colors live in the `FRAMES` and `CUSH` arrays at the top of the `<script>`.
- The big preview is inline SVG (ids like `bandMain`, `cupL`, `cushTexR`).
- Thumbnails are generated by the `thumb()` function.
